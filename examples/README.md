# Examples

Worked demonstrations, grouped by the layer of the system they exercise.

The root examples and the v3 set show **prose being repaired**. The v6 set shows
**a decision being governed**. Both are real work; they answer different
questions, and the second one is newer, so start wherever your problem is.

---

## Prose repair (v1–v3)

A draft goes in, the passes run, and a better draft comes out. The unit of work
is a paragraph and you assess the result by reading it.

- [`01-ai-slop-to-human.md`](01-ai-slop-to-human.md) — generic AI output rebuilt into specific, voiced prose. Score 31 → 87.
- [`02-corporate-to-strategy.md`](02-corporate-to-strategy.md) — buzzword announcement rebuilt as a strategy memo with numbers and owners. Score 28 → 93.
- [`03-weak-academic-to-strong.md`](03-weak-academic-to-strong.md) — vague unsourced student writing rebuilt as evidence-dense argument. Score 38 → 88.
- [`04-fiction-telling-to-showing.md`](04-fiction-telling-to-showing.md) — named emotions replaced with scene, sensory detail and subtext. Score 34 → 92.
- [`05-genre-transfer-academic-to-sermon.md`](05-genre-transfer-academic-to-sermon.md) — the same loneliness data delivered as scholarship and then as a pastoral address. Same facts, rebuilt delivery.

## v6 examples

- [`v6/README.md`](v6/README.md) — four walkthroughs of the Sovereign Meaning Runtime, with transcripts recorded from the tool.

Under v6 the semantic state is canonical and a rendering is a build from it, so
these examples are not before-and-after text. The output of one is usually a
refusal, a cost estimate for a change that does not exist yet, a disagreement
that was preserved rather than settled, or a file a stranger can check offline.
Success is frequently a non-zero exit code.

- [`v6/01-simulate-before-you-edit.md`](v6/01-simulate-before-you-edit.md) — a grant figure moves. Ask what that would cost before the change exists, then repair one node instead of the manuscript.
- [`v6/02-the-merge-that-refused.md`](v6/02-the-merge-that-refused.md) — 11,800 against 12,400. The merge stops, exits 2, keeps both numbers, and never writes the average.
- [`v6/03-authority-that-expires.md`](v6/03-authority-that-expires.md) — a reviewer helps for two weeks. The same decision succeeds inside the window and is refused after it, with nobody revoking anything.
- [`v6/04-a-capsule-a-stranger-verifies.md`](v6/04-a-capsule-a-stranger-verifies.md) — a funder verifies one claim, offline, from two files, without receiving the workspace.

Read `01` first. Simulation is the command that changes how the work feels.

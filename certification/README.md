# Operator Certification

Writing Intelligence v3.0 introduces an optional operator certification path. Certification is for users who want to demonstrate mastery: agencies, editorial teams, ghostwriters, grant consultants, ministry communications staff, content shops.

Certification is **not required to use Writing Intelligence**. The skill is free and open. Certification exists for operators who want to be discoverable, hireable, and verifiable as practitioners of the v3.0 doctrine.

## The Three Tiers

| Tier | What It Means | Verification |
|---|---|---|
| **Apprentice** | Has demonstrated baseline use of the 11-pass kernel on real work | Self-audit + benchmark submission |
| **Operator** | Has shipped work scored ≥ 85 on prose quality + epistemic integrity across 5+ deliverables | Maintainer review + portfolio audit |
| **Architect** | Can extend the system: build new genre packs, voiceprints, schemas, or agents per the RFC process | Accepted RFC + merged contribution + portfolio |

## Apprentice

**Requirements**:

- Read SKILL.md, README.md, USER_GUIDE.md
- Complete 3 real deliverables using the 11-pass kernel
- Submit them with the intake contract, scorecard, and any pass artifacts
- Score ≥ 80 on prose quality

**How**: open an issue with the `apprentice-application` label and link your three deliverables (publicly viewable or shared with maintainer).

**Outcome**: name added to `certification/operators.md` with `apprentice` tier.

## Operator

**Requirements**:

- Apprentice tier confirmed
- 5+ shipped deliverables across 3+ arenas (e.g., grant + sermon + newsletter)
- Each deliverable scores ≥ 85 prose + ≥ 85 epistemic integrity (when applicable)
- Maintainer review of the portfolio

**How**: open an issue with the `operator-application` label.

**Outcome**: name added with `operator` tier. Discoverable as a v3.0 operator.

## Architect

**Requirements**:

- Operator tier confirmed
- At least one accepted RFC contributing to the doctrine
- At least one merged PR adding a genre pack, voiceprint, schema, or agent
- Demonstrated ability to teach the system to others

**How**: by invitation after meeting the requirements.

**Outcome**: name added with `architect` tier. Co-maintainer privileges considered.

## Why

Open-source projects collapse without a clear quality signal. Certification gives:

- Hiring teams a way to find verified operators
- Operators a credential they can earn
- The community a way to recognize meaningful contribution
- Maintainers a path to grow the architect bench responsibly

## What Certification Is Not

- Not a paid product. There is no fee.
- Not a gate to using the skill. Use it freely. Forever.
- Not exclusive to professionals. A high-school journalist can be an Apprentice.
- Not Anthropic-related. Anthropic does not endorse this skill; this is community-run, authored by Antonio T. Smith Jr.

See `certification/operator_levels.md` for tier-level scoring rubrics and `certification/exam_rubrics.md` for the audit format.

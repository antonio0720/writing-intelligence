# Action as Controlled State Transition, Not Kinetic Decoration

**Normative scope:** C132–C145. The actor's body, viewpoint, movement, location, objective and resources form a locally closed state at each authored beat. Every declared movement must use an authorized edge of the fight space, unless a separately canonical ability supplies an exception. Each resource change is applied to the actor's own stock; underflow is a logical defect. Restoration demands a causal explanation. A visibility claim from a limited viewpoint must be supported by line-of-sight or a declared nonvisual awareness mechanism.

A fight is not graded by violence quantity. Physical victory can be a failure against an emotional or strategic objective; the end state should record losses and future options. Set–Rise–Twist–Tie is one available scaffold, not a compulsory pacing algorithm. Sound and prose compression respond to medium and audience, not a formula.

The standalone fixture is a topology *declaration*: an unrepresented door, capability or item does not prove a manuscript error until extraction completeness is established. Report structural failures **relative to declared geometry**, not omniscient claims about prose never parsed.

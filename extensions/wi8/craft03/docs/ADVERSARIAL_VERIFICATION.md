# Falsification and Release Evidence

## Test distinctions

- **Mechanical checks:** non-existent scene refs, event causal cycles, closed goal hierarchy, movement via declared edges, resource underflow, visibility under limited viewpoint.
- **Causal diagnosis:** unfair retroactive clue, unearned twist, open pledge debt, plan requiring unconstrained human behavior, new goal without causal link, false source-freshness claim.
- **Aesthetic review only:** emotional stakes, character entrance quality, desired suspense trajectory, antagonist sympathy, pace and compression, catharsis and cultural representation.
- **Reader observed:** real consented reader assessments must state sample, genre, questions, author/reader blinding if any, audience variation and disagreement. No synthetic fixture is such evidence.
- **Publication readiness:** typography, copyedit, permissions, format proof, platform metadata, reader/aesthetic review and authorized release belong outside this module. This CLI *always* holds publication.

## Critical negative controls

1. An intentionally quiet opening passes without requiring violence or shock.
2. A reverse-time opening with declaration passes; absent disclosure prompts review.
3. A fight across nonadjacent spaces blocks; a canonical teleport exception needs independent source verification upstream.
4. A character cannot observe across an undeclared sight line.
5. Consuming more ammunition than is declared blocks; unearned stamina gain prompts review.
6. A repeated maneuver can be an intentional callback. No automatic deletion.
7. An antagonist plan with a unique independent response and no contingency prompts causal review.
8. A character cannot use information absent from their known-state projection.
9. Locally successful sequence outcome can carry antagonist benefit without contradictory scalar grading.
10. Later interpretation must not mutate the earlier observer's versioned record; as-of queries preserve state.
11. Current governmental/military/scientific references with missing check date prompt provenance review.
12. A novel-to-audio transformation that changes core meaning IDs cannot self-certify semantic equivalence.
13. An input claiming `canonical_export` is refused because no trusted graph adapter is implemented.
14. Even all-green mechanical checks cannot produce a release verdict of publication-ready.

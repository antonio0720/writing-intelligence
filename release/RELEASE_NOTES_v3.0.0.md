## What's New in v3.0

### 11-Pass Governed Kernel

Where v2.0 had 7 passes, v3.0 has 11. The four new passes — Intake Contract, Corpus & Context Ingestion, Genre & Arena Alignment, and Memory & Benchmark Update — turn writing from a compile-and-ship loop into a governed lifecycle.

### 12 Engines

Intake Contract · Corpus Governance · Voice Fingerprint · Genre Stack · Architecture Graph · Epistemic Ledger · Prose Compiler · Narrative Intelligence · Arena Delivery · Benchmark & Regression · Agent Orchestration · Certification & Governance

### 12 Specialist Agents — The Writing Board

Intake Architect · Corpus Auditor · Voice Fingerprinter · Genre Marshal · Structure Engineer · Evidence Prosecutor · Sentence Surgeon · Dialogue Commander · Narrative Architect · Stress Tester · Scorekeeper · Delivery Packager. Runs as one skill or as multi-agent orchestration. Conflict resolution rules included.

### 11 Machine-Readable Schemas

Every pass artifact is now a JSON Schema-validated object: `intake_contract`, `corpus_map`, `voice_fingerprint`, `genre_stack`, `architecture_graph`, `epistemic_ledger`, `prose_rewrite_log`, `storyworld_memory`, `delivery_bundle`, `benchmark_result`, `agent_task`. Schemas unlock CLI execution, MCP server execution, web app integration, CI writing checks, automated scoring, benchmark reports, reproducible outputs.

### 11 New Domain Packs

Grant / NOFO · Technical Documentation · Journalism · Resume / Cover Letter · Social Media · YouTube Script · Newsletter · Real Estate · Loan Officer · Church Leadership · Small Business Operator. Each obeys the 15-section Domain Pack Schema. Each ships with 5 benchmark cases.

### Voice Fingerprint Engine

Voiceprints become measurable. Build a fingerprint from 3+ samples. Detect drift. Enforce team voice. Distinguish character voices in fiction. New voiceprint: **courageous_builder** — reusable for branded operator personas.

### Genre Stack Engine + Collision Matrix

Multiple genre packs operate simultaneously. The Genre Marshal resolves conflicts across 8 dimensions: evidence discipline, cadence, compression, warmth, persuasion, compliance, formality, narrative distance. A "church grant proposal in plain language with sermon-level dignity but government-level precision" is a first-class request now.

### Epistemic Ledger (Mandatory High-Stakes)

Claim classification with source status. Mandatory in academic, medical, legal, government, grant, and financial domains. Hard-blocks fabrication. The Evidence Prosecutor cannot be overridden by the Scorekeeper.

### Narrative Intelligence + Storyworld Memory

v2.0 Fiction Intelligence extends into longform series architecture. Storyworld memory persists across sessions. Series arc audit. Cross-book voice fingerprint stability. Foreshadowing ledger (planted / paid off / orphaned).

### Arena Delivery Engine

One approved piece becomes many delivery bundles. 20+ arenas: memo, grant_response, sermon, caption, article, chapter, email, pitch_slide, youtube_script, newsletter, government_brief, sop, speech, landing_page, linkedin_post, twitter_thread, instagram_caption, press_release, case_study, blog_post.

### Benchmark Harness

60 benchmark cases across 12 categories. Release gates enforce: score improvement (v3 must beat v2 by ≥ 5 on ≥ 70% of cases), no regression (≤ 3-point drop), evidence safety (100% fabrication-trap recall), voice preservation (≥ 80% drift-direction recall), output packaging (every bundle validates).

### Operator Certification

Optional. Free. Three tiers: Apprentice → Operator → Architect. Audit format described in `certification/exam_rubrics.md`.

### Governance

`governance/RFC_PROCESS.md` formalizes structural contributions. `governance/ADR_TEMPLATE.md` records architectural decisions. `governance/RELEASE_CHECKLIST.md` gates every release. `governance/VERSIONING.md` enforces semver discipline.

### Documentation Reframe

`docs/MIGRATION_v2_to_v3.md` · `docs/OPERATOR_MANUAL.md` · `docs/BUILDER_GUIDE.md` · `docs/DOMAIN_PACK_GUIDE.md` · `docs/VOICEPRINT_GUIDE.md` · `docs/api/API_SPEC.md` · `docs/mcp/MCP_SPEC.md` · USER_GUIDE.md expanded to 250+ prompts organized by operator tier.

## Migration

v3.0 is **purely additive**. v2.0 prompts continue to work. The 7-pass kernel is preserved inside the 11-pass kernel. See `docs/MIGRATION_v2_to_v3.md` for the step-by-step guide.

For high-stakes work (academic / medical / legal / government / grant / financial), the Epistemic Ledger is now mandatory. For cross-arena distribution, Arena Delivery Bundles replace ad-hoc reformatting.

## Install

**Claude.ai**: Settings → Skills → Install from file → select `writing-intelligence.skill` from the Releases page.

**Claude Code**:

```bash
git clone https://github.com/antonio0720/writing-intelligence ~/.claude/skills/writing-intelligence
```

**Claude Projects**: Upload SKILL.md and the `references/`, `schemas/`, `agents/` folders.

**Any LLM**: Include SKILL.md in your system prompt.

**MCP / API integration**: See `docs/api/API_SPEC.md` and `docs/mcp/MCP_SPEC.md`. Reference implementations ship in v3.1.
